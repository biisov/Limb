# Limb

Простое Android-приложение: крутящийся лимб как на сейфе (метки без цифр), единственная цель — приятные щелчки при вращении.

- **По часовой** — обычный щелчок. **Против часовой** — храповой щелчок с «прокрутом» (быстрый трещоточный хвост).
- Крутится пальцем (с инерцией при броске).
- **Кнопки громкости**: `+` крутит по часовой, `−` против, пока кнопка зажата — вращение не останавливается. Отпустил — лимб плавно тормозит.
- Тактильный отклик на каждый щелчок, экран не гаснет.

Пока приложение открыто, кнопки громкости перехватываются (системная громкость ими не меняется).

## Сборка

APK собирается GitHub Actions при каждом пуше (`Actions → Build APK → limb-debug-apk`). Локально:

```
./gradlew assembleDebug   # app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK (platform 35).

## Настройка

- Скорость вращения при удержании, трение, число меток — константы в `DialView.kt` (`companion object`).
- Звуки синтезируются скриптом `tools/gen_sounds.py` (stdlib, без зависимостей) в `app/src/main/res/raw/`. Подкрутить тембр → поправить скрипт и запустить заново.
