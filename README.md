# Limb

Простое Android-приложение: крутящийся лимб как на сейфе (шкала 0–55), единственная цель — приятные щелчки при вращении.

- **Звук** — две готовые записи, играются как есть, без обработки: `res/raw/click_cw.ogg` (по часовой) и `res/raw/click_ccw.ogg` (против). Файлы фактически AAC в MP4 (исходные `.m4a`), переименованы только по имени.
- **Вибрация** — короткий «тик» на каждое деление, синхронно со звуком. По часовой — сильный и чёткий (`CLICK`), против часовой — слабее и мягче (`TICK` на малой силе).
- **Слот над лимбом** — `@id/ad_container` (`activity_main.xml`): ~72% ширины, ~13% высоты, верх на ~15% экрана; если не помещается рядом с указателем, сдвигается выше (лимб не трогается). Сейчас внутри замок (`@id/ad_placeholder`); для баннера удалить замок и добавить баннер в контейнер. Приложение зафиксировано в портретной ориентации.
- Крутится пальцем (с инерцией при броске). Одно деление шкалы (6°) = один щелчок = один тик.
- **Кнопки громкости**: `+` по часовой, `−` против. Короткое нажатие — ровно одно деление. Зажатие — через ~400 мс лимб крутится сам, ~13 делений в секунду, пока кнопка не отпущена. Системная громкость при этом не меняется.

Пока приложение открыто, кнопки громкости перехватываются.

## Отрисовка

`DialView` рисует лимб кодом (Canvas), два слоя:

- **Вращается**: ромбовидная насечка на внешнем кольце (один раз рендерится в Bitmap), деления и цифры.
- **Неподвижно** (свет как от лампы сверху): тени под лимбом, блик/тень на кольце насечки, затенение по краю шкалы, указатель, центральная шайба с бликом.

Геометрия и цвета — из `genesis4.py` (дизайн 1080×1920), все размеры в «единицах дизайна» и масштабируются под экран.

## Сборка

APK собирается GitHub Actions при каждом пуше (`Actions → Build APK → limb-debug-apk`). Локально:

```
./gradlew assembleDebug   # app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK (platform 35).

## Настройка

- Трение, число делений — константы в `DialView.kt` (`companion object`); задержка и скорость при удержании кнопки громкости — в `MainActivity.kt`.
- Звуки: заменить файлы `click_cw.ogg` / `click_ccw.ogg` в `app/src/main/res/raw/` (имена — латиница, цифры, `_`).
