# Ускорение телевизора TCL 65C645 без рекламы: заметки для Claude

Хозяин телевизора не программист. Объясняй просто, по-русски. Всё на пульте нажимает он: говори, что нажать.
Всё на компьютере делаешь сам. Основа: Free My TV (github.com/simbasjungles/free-my-tv), лёгкий главный экран вместо
оболочки производителя, лишнее выключается без удаления, кнопка «Original» возвращает всё.
Источник правды: сам телевизор (adb), а не статьи про похожие модели.

## Правила (от хозяина, не обсуждаются)

- Не удалять и не чистить системные приложения: только `pm disable-user --user 0`, никогда `uninstall` и `pm clear`.
- Не выключать приложение, сохранившее Wi-Fi: Android сотрёт сеть (проверку `wifiOwners` в Free My TV не обходить).
- Не жать клавиши в меню телевизора вслепую: меню открывается там, где его оставили, стрелки меняют чужие настройки.
  Перед каждым шагом смотри на экран: `adb exec-out uiautomator dump /dev/tty` (текст экрана) или
  `adb exec-out screencap -p > screen.png`.
- Сервисное меню только с согласия хозяина, и там ТОЛЬКО ADB. Panel, Backlight, Init и прочее могут сломать телевизор.
- Не просить пароли, ключи и токены в чат (ключ TMDB он вставляет в `config.properties` сам).
- Скачивать только из официальных источников, подпись APK проверять (`apksigner verify --print-certs`).
- Выключать только то, на что хозяин сказал «да». Переключает на Free My TV он сам, на телевизоре.
- Остановись и спроси, если: Android ниже 9; ADB не включается без сервисного меню; действие нельзя откатить.
- Не коммитить `backups/`, `measurements/`, `apps.tsv`, `config.properties`, `*.keystore`, APK (см. `.gitignore`).

## Готово, когда

Новый экран работает, «Домой» ведёт в него, клавиатура и Wi-Fi на месте, память выросла (цифры до/после),
откат проверен.

## Что уже сделано (облачная сессия, 2026-10-25)

- Прочитаны README и CLAUDE.md Free My TV. Для TCL там уже есть `DEBLOAT` (TCL Channel, сообщения, демо магазина,
  отельное меню, инструкции, зеркалирование, логи) и `PROTECTED` (настройки TCL, клавиатура TCL
  `com.tcl.inputmethod.international`, Gboard, входы, пульт, Bluetooth, Wi-Fi overlay).
- Написаны скрипты в `tv/` и проверены на имитации adb (не на телевизоре): копия и проба отката ничего не пишут,
  откат возвращает изменения Free My TV в правильном порядке, повторная проба после отката — «отличий нет».
- Телевизор ещё не подключался: облако не видит домашнюю сеть. Всё дальше делается с компьютера хозяина.
- Ждём от хозяина: фото «Настройки → Система → Об устройстве».
- Город для погоды: **Тюмень** (`latitude=57.1522`, `longitude=65.5272`, `city=Тюмень`, `tmdb_region=RU`,
  `temperature=C`). Часовой пояс Тюмени Asia/Yekaterinburg, по нему Free My TV показал бы Екатеринбург, поэтому
  город задаём явно. Валюту и криптовалюты (`show_crypto`, `currency`) спросить.

## Компьютер хозяина: Windows

- Скрипты запускать в Git Bash (`bash tv/backup.sh …`), Python: `py tv/find-tv.py` (или `python`).
- Поставить недостающее только из официальных источников: Git for Windows, Python 3, Android platform-tools
  (adb), JDK 17 (Temurin), Android command-line tools → `sdkmanager "build-tools;34.0.0" "platforms;android-34"`.
- `lib.sh` выключает переделку путей Git Bash (`MSYS_NO_PATHCONV`), иначе `/data/...` на телевизоре превращается в
  `C:/Program Files/Git/data/...`; пути на компьютере для adb/aapt2 идут через `native` (`cygpath -m`). Новые
  вызовы adb с локальными путями тоже оборачивать в `native`.
- Брандмауэр Windows может спросить про adb или Python при первом подключении: разрешить для частной сети.

## Скрипты (`tv/`, bash 3.2+ и Python 3, работают на macOS, Linux, Git Bash)

| Скрипт | Что делает | Меняет телевизор? |
|---|---|---|
| `python3 tv/find-tv.py [192.168.1]` | ищет открытый порт 5555 в своей сети /24 | нет |
| `tv/backup.sh <IP> [папка] [--no-apk]` | копия: пакеты и состояние, settings global/secure/system, главный экран, клавиатуры, Wi-Fi (без паролей, с `cname`), входы/HDMI, APK ваших приложений, SHA256SUMS; кладёт рядом `restore.sh` | нет |
| `tv/restore.sh <копия> <IP>` | ПРОБА отката: печатает команды | нет |
| `tv/restore.sh <копия> <IP> --apply` | откат: выключает Free My TV (если его не было), возвращает удалённое для пользователя, ставит ваши APK, включает выключенное (setupwraith последним), главный экран, клавиатуру, заставку, спецвозможности, доступ к уведомлениям. Прочие настройки только показывает | да |
| `tv/measure.sh <IP> before\|after` | /proc/meminfo (3 раза, медиана), dumpsys meminfo, df, PSS главного экрана | нет |
| `tv/compare.sh <до> <после>` | таблица до/после | — |
| `tv/deps.sh <IP>` | кто обслуживает клавиатуру, настройки, Wi-Fi, Bluetooth, входы ТВ, заставку; помечает, если это в `DEBLOAT` | нет |
| `tv/apps.sh <IP>` | `apps.tsv`: пакет, вкл/выкл, системное/своё, название (aapt2), «выключит сам»/«защищено» | нет |

`deps.sh` и `apps.sh` ищут Free My TV в `./free-my-tv` (папка в `.gitignore`).

## План (шаги хозяина)

1. **Версия Android** по фото «Об устройстве» (после подключения сверить с `getprop ro.build.version.release`).
   Ниже 9: Free My TV не ставим, предложи облегчённый вариант (только выключение рекламных приложений через
   `pm disable-user` по согласию + откат) и спроси.
2. **Отладка.** На Google TV: Настройки → Система → Об устройстве → «Сборка ОС Android TV», 7 раз OK →
   Настройки → Система → Для разработчиков → «Отладка по USB». На TCL это открывает ADB по сети на 5555.
   Нет пункта: ищи способ для этой модели; сервисное меню только с согласия, и там только ADB.
3. **Найти телевизор:** `python3 tv/find-tv.py`, затем `adb connect <IP>:5555`. Не нашёлся: IP из
   Настройки → Сеть и Интернет. На экране «Разрешить отладку?»: «Всегда» + «Разрешить».
4. **Копия и откат до любых изменений:** `tv/backup.sh <IP>` → `tv/restore.sh backups/<папка> <IP>` (проба: должно
   быть «Отличий от копии нет»). Доказать, что проба ничего не меняет: `tv/backup.sh <IP> backups/check --no-apk`
   и `diff -r` по `packages/` и `settings/` с первой копией (допустимы только счётчики, которые Android меняет сам).
5. **Замер «до»:** перезагрузить телевизор, 3 минуты на главном экране, `tv/measure.sh <IP> before`.
6. **Оболочка производителя:** `tv/deps.sh <IP>` и `backups/*/input/`, `wifi.txt`, `tv_input.txt`. Всё, что
   обслуживает клавиатуру, настройки, Wi-Fi, входы HDMI и не в `PROTECTED`, добавить в `PROTECTED` в
   `free-my-tv/app/src/io/freemytv/HomeMode.java`. Если клавиатура по умолчанию живёт в оболочке TCL: сначала
   поставить LeanKeyboard с github.com/yuliskov/LeanKeyboard/releases (автор SmartTube), проверить подпись
   (`apksigner verify --print-certs`; сертификат должен совпадать между релизами автора), включить и выбрать её, и
   только потом что-то менять. Wi-Fi: если в `wifi.txt` у сети `cname=com.google.android.tungsten.setupwraith`,
   Free My TV попросит забыть сеть и подключиться заново (пароль хозяин вводит сам, на телевизоре).
7. **Список приложений:** `tv/apps.sh <IP>`, показать хозяину таблицей с понятными русскими названиями и что
   делает каждое. Отдельно показать, что Free My TV выключит сам при переключении (`DEBLOAT`, плюс стоковый главный
   экран и заставка, без них он не работает) — это тоже требует его «да»: от чего он отказался, убрать из `DEBLOAT`
   до сборки. Что он хочет выключить сверх списка — добавить в `DEBLOAT` (тогда «Original» вернёт и это), не
   выключать вручную. Спросить про `disable_assistant` (Google Ассистент, кнопка микрофона перестанет работать).
8. **Сборка и установка** по `free-my-tv/CLAUDE.md` («Installing it for someone»): JDK 17, build-tools 34,
   android-34, `./build.sh`, город в `config.properties` (спросить; иначе из часового пояса телевизора
   `settings get global time_zone`), `adb install -r FreeMyTV.apk`, на TCL
   `appops set io.freemytv AUTO_START allow || appops set io.freemytv APP_AUTO_START allow`.
   Хранить `freemytv.keystore`. `adb disconnect`, потом хозяин сам: Free My TV → Home Screen → Free My TV,
   «Разрешить отладку» для Free My TV: «Всегда». Проверка: `adb logcat -s FreeMyTV`.
9. **Замер «после»** в тех же условиях: `tv/measure.sh <IP> after`, `tv/compare.sh`. Проверить вместе с
   хозяином: «Домой» ведёт в новый экран, клавиатура появляется (поиск в YouTube), Wi-Fi подключён, HDMI-входы
   открываются из нижней панели.
10. **Напомнить:** выключить «Отладку по USB» (Настройки → Система → Для разработчиков); Free My TV после этого
    не сможет сам переключаться и откатываться, пока отладку не включат снова, — сказать об этом. Где откат:
    на телевизоре Free My TV → Home Screen → Original; на компьютере `backups/<папка>/restore.sh`.
